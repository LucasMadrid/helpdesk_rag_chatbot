# Approved Software Catalogue and Requests

This page lists the applications approved for use on Corvane laptops and explains how to install them or request something that is not on the list. The catalogue is reviewed every quarter by End-User Computing and Security Operations. Versions shown are the minimum supported versions; DeviceDock keeps installed applications up to date automatically.

## Catalogue

Applications marked Pre-approved can be installed by anyone from the DeviceDock Company Portal without a ticket. For all other applications, the named approver must approve a request in Assist before the licence is assigned. Costs are per user per year and are charged to your department's cost centre.

## How to install or request software

1. Open the DeviceDock Company Portal on your laptop and search for the application.
2. If the application is Pre-approved, select Install. Installation usually finishes within 15 minutes; restart if the portal shows `Restart required`.
3. If the application needs approval, select Request in the portal. This opens a pre-filled request in Assist at assist.example.com.
4. Add a one-line business reason and, for paid applications, confirm the cost centre. Assist sends the request to the approver shown in the table.
5. After approval, End-User Computing assigns the licence and the application becomes installable in the DeviceDock Company Portal, normally within 2 working days.
6. If the application you need is not in the catalogue, raise a New software request in Assist. Include the vendor name, the purpose, the data the tool will process and whether it stores data outside Corvane systems.
7. Non-catalogue applications need a security review by Security Operations before they can be approved. The review takes 10 working days from the date all requested information is provided. Applications that process customer freight or warehouse data may also need a data protection assessment, which can add time.
8. If the review passes, the application is added to the catalogue with an approver and you are notified in the ticket. If it fails, Security Operations suggests an approved alternative where one exists.

## Temporary admin rights

Corvane laptops run without local administrator rights. If you need admin rights to install development dependencies or test software, request Temporary admin rights in Assist with a reason and your line manager's approval. Admin rights are always temporary: they are granted for a maximum of 30 days and removed automatically by DeviceDock when the period ends. You can request a new period if the need continues, but each request is reviewed again. Admin rights do not allow you to install applications that failed a security review or to disable SecureLink, DeviceDock or endpoint protection.
